# LowCostPDF.xyz

LowCostPDF.xyz is a privacy-first, browser-based PDF utility designed to reduce printing costs by arranging multiple PDF pages on a single A4 sheet.

## 🌐 Live Website

https://www.lowcostpdf.xyz

## ✨ Features

- Arrange 2, 4, 6, 9, or 16 PDF pages per A4 sheet
- Default 4-up layout for up to 75% paper savings
- Process PDF files entirely in the user's browser
- No file upload to a server
- No registration or software installation
- Mobile and desktop browser support
- English and Bengali-focused resources
- Privacy-friendly static architecture

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript
- PDF-lib
- Cloudflare Pages
- Google Search Console
- Google AdSense
- GitHub

## 🔒 Privacy Architecture

PDF processing takes place entirely on the user's device. Documents are not uploaded to or stored on a LowCostPDF server.

## 🎯 Primary Use Cases

- University lecture notes
- Student handouts
- Presentation slides
- Office documents
- Previous examination questions
- Low-cost A4 printing

## 🚀 Deployment

The production website is deployed using Cloudflare Pages.

## 📂 Project Structure

- `index.html`: Main PDF tool
- `about.html`: Project information
- `privacy.html`: Privacy policy
- `terms.html`: Terms of use
- `robots.txt`: Search-engine crawling rules
- `sitemap.xml`: Search-engine sitemap
- `ads.txt`: Authorized AdSense seller information
- `_headers`: Cloudflare response header configuration
- `_redirects`: Cloudflare Pages redirect configuration
- SEO guide pages: Educational content about PDF printing and cost reduction
